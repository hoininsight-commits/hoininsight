# Gemini 기반 유튜브 URL 스크립트 확보 실현 가능성 검토 보고서

**작성일**: 2026-04-18 (KST)  
**목적**: YouTube IP 차단(HTTP 429) 우회를 위한 Gemini API 스크립트 직접 추출 타당성 검증  
※ 본 보고서는 추정이 아닌 실제 API Call 로그(`test_gemini_api.py`) 및 결과를 바탕으로 작성되었습니다.

---

## 1) 검토 대상
- **검토한 방식**: Gemini API 네이티브 멀티모달 프롬프팅 (Video URL Direct Injection)
- **테스트한 환경**: Python `google-generativeai` 라이브러리, `gemini-2.5-flash` 모델
- **사용한 입력 방식**: API의 `file_data` Part 파라미터에 `file_uri: https://www.youtube.com/watch?v=...` 형태로 URL 직접 투입

---

## 2) 테스트 결과

### 공개 영상 테스트 (최근 영상 `oac8R4R0CEY` 테스트 완료)
- **URL 읽기 가능 여부**: **[성공]** 별도의 다운로드 장치 없이 Gemini 내부망을 통해 영상을 획득하여 분석함. (IP 429 차단 우회 가능)
- **결과 형태**: **[스크립트 원문에 근접]**
  - 추출된 텍스트 확인 결과, 경제사냥꾼의 오프닝(*"안녕, 남들이 못 보는 경제의 이면을 분석하는..."*)과 클로징 멘트, 숫자 팩트(영업이익 792조, 140조 유입 등)가 생략 없이 그대로 서술되었습니다.
  - 단순 요약과 재구성이 아닌 **순차적 발화 텍스트(Verbatim Transcript)** 구조를 확보할 수 있었습니다.
- **품질 평가**: 화자의 구어체 뉘앙스까지 보존하므로, 우리의 "팩트/해석 분리 분석" 파이프라인의 입력값으로 충분히 활용 가능합니다.

### 제한 영상 검토 (멤버십/비공개/로그인)
- **가능 여부**: **[불가]** 
- **사유**: Gemini API는 호출자의 로컬 브라우저 세션이나 `youtube_cookies.txt`를 공유받지 않습니다. 익명(Anonymous)의 Google 서버로서 접근하므로 시청 권한이 제한된 영상은 읽을 수 없습니다.

---

## 3) 자동화 연결성 평가

- **수동 / 반자동 가능 여부**: 웹 UI 및 스크립트를 통해 언제든 가능.
- **API 자동화 가능 여부**: **[최상]** 기존의 `transcript_ingestor.py` 내부에 완전 자동화 코드로 편입할 수 있습니다. 이미 서버에 `GEMINI_API_KEY`가 구비되어 있으므로 환경적 준비가 완료된 상태입니다.
- **우리 파이프라인 연결 난이도**: **(하)** 
  `youtube-transcript-api` $\rightarrow$ `yt-dlp` $\rightarrow$ `Gemini API` 순으로 3단계(Engine 3) Fallback 로직을 구성하면 기존 파이프라인의 구조 변경 없이 즉시 적용 가능합니다.

---

## 4) 최종 판정

> **"Gemini URL 기반 스크립트 확보 방식은 공개 영상 한정으로 '적합'하다."**

- **이유**: 클라우드 IP 차단(429) 문제를 완벽히 우회할 수 있으며, 프롬프트 강제를 통해 요약이 아닌 원문 수준의 텍스트를 반환하기 때문입니다.
- **원문 스크립트 확보 적합성**: '요약하지 말고 발화 순서대로 텍스트만 도출하라'는 프롬프트로 재구성/할루시네이션(Hallucination) 억제 실증 완료.
- **Fallback 용도 적합성**: 가장 강력한 방어막으로 작용할 수 있습니다.

---

## 5) 권고안 (Action Items)

1. **실제 도입 추천 여부**: **강력 추천**합니다. 현재 429 에러로 멈춘 파이프라인에 당장 숨통을 틔울 수 있는 유일한 대안입니다.
2. **도입 시 권장 구조**: **투트랙(Two-track) 하이브리드 구조**
   - **엔진 1**: 기존 `youtube-transcript-api` + `yt-dlp (with Cookie)` 
     *(멤버십 영상 및 고정밀 자막 확보용)*
   - **엔진 2**: Gemini API URL Direct
     *(공개 영상 중 IP 차단으로 인해 1번 엔진이 막혔을 때 구동되는 안전망)*
3. **주의사항**: 이 방식을 남용할 경우 Gemini API 쿼터 비용이 부과될 수 있으므로, 반드시 1차 엔진이 실패했을 때만 호출되도록 조건부 실행을 설계해야 합니다.
