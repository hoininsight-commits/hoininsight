## 🎭 콘텐츠 타입별 구조 (Dual Mode)

### 1. NORMAL CONTENT (설명형)
- **대상**: `classification == NORMAL`
- **핵심**: "왜 이런 일이 당연하게 일어나는가?"를 질문하고 3가지 시나리오로 해설
- **흐름**: 도발적 질문 → 정상 흐름 분석 → 시나리오 제시 → 데이터 결론 → 액션(WATCH/WAIT)

### 2. ANOMALY CONTENT (핵심형)
- **대상**: `classification == ANOMALY`
- **핵심**: "이건 말도 안 되는 모순이다"를 강조하며 숨겨진 기회 포착
- **흐름**: 모순 제시 → 정상 vs 실제 데이터 대비 → 괴리 원인 분석 → WHY NOW → 액션(OPPORTUNITY/RISK)
