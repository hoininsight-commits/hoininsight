# FACT_CHECKER 설계 원칙
v1.0 | 2026-04-20

## 역할
생성된 스크립트 내에 포함된 모든 수치를 원천 데이터와 대조하여, AI의 환각(Hallucination)이나 단순 오기로 인한 데이터 무결성 훼손을 방지한다.

## 입력 / 출력
- **입력**: 생성된 스크립트(MD), `data/raw/` 전체 수치 데이터
- **출력**: `fact_check_report.json`, 수정된 스크립트 (오류 발견 시)

## 핵심 로직
1. **Numeric Extraction**: 스크립트 내에서 금리, 가격, 비율, 날짜 등 모든 수치 추출
2. **Raw Data Cross-Check**: 추출된 수치를 실제 JSON 파일 내의 값과 1:1 대조
3. **Contextual Validation**: 수치의 방향성(상승/하락)이 데이터와 일치하는지 확인
4. **Auto-Correction**: 단순 수치 오류의 경우 원천 데이터 기반으로 자동 교정

## 수정 시 주의사항
- "5년 만에", "3일 연속" 등 기간 표현을 지표 수치로 오인하지 않도록 정규식(Regex) 보완 필요
- 임계값(Threshold) 비교 시 허용 오차 범위 설정 주의

## 알려진 이슈
- 단위 변환(예: 억 원 vs 조 원) 과정에서 드물게 오판 발생 가능
