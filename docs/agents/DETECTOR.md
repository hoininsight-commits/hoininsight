# DETECTOR 설계 원칙
v1.0 | 2026-04-20

## 역할
수집된 시장 데이터에서 통계적 이상징후(Anomaly)를 감지하고, "경제사냥꾼" 내러티브에 적합한 오늘의 Top-1 토픽을 자동 선정한다.

## 입력 / 출력
- **입력**: `data/raw/` 하위의 매크로, 시장, 센티먼트, 수급 데이터(JSON)
- **출력**: `today_signal.json` (최종 선정 토픽), `candidates.json` (후보군 리스트)

## 핵심 로직
1. **Z-score 분석**: 각 지표의 최근 20일/90일 평균 대비 편차 계산 (SPEED 관점)
2. **모순 탐지 (Mismatch)**: 
   - Price-Sentiment 모순 (뉴스는 악재인데 지수는 상승 등)
   - Asset-Asset 모순 (금리 상승 시 기술주 동반 상승 등)
3. **WHY NOW 산출**: 지표의 임계점 돌파 또는 방향 전환(Flip) 시점을 트리거로 정의
4. **Scoring & Selection**: 강도(Strength), 데이터 완결성, 엔트로피를 종합하여 최적의 주제 1개 선정

## 수정 시 주의사항
- 단순히 "말이 되는" 주제가 아니라, "데이터가 충돌하는" 주제를 우선시하도록 가중치 조절 필요
- JSON 파싱 오류 방지를 위해 `extract_json` 유틸리티와 `response_mime_type` 필수 사용

## 알려진 이슈
- 특정 지표 수집 실패 시 전체 Z-score 계산이 skip되는 현상 (보완 중)
