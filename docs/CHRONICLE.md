## 📅 2026-05-01 (v18.5 [The Intelligent Discovery Hunter] 지능형 토픽 사냥 및 비용 최적화)

### 1. [Context] 오늘의 시작
*   기존의 통계적 방식(Bi-gram)이 금리, 인플레 같은 뻔한 거대 담론에 매몰되는 문제 해결 요청.
*   시장 지표와 소셜 시그널(Polymarket, HN)을 결합하여, 오늘만의 '구체적이고 신선한 10대 사건'을 포착하는 지능형 엔진 구축 지시.

### 2. [Milestones] 성공한 것
*   **지능형 토픽 사냥 엔진 (v2.9) 완성**:
    *   **LLM 기반 추출**: 단순 빈도수가 아닌 제미나이가 문맥을 읽어 10개의 독립적인 사건(Event)을 추출하도록 로직 전면 개편.
    *   **하이브리드 인텔리전스 (v1.5)**: RSS 뉴스에 예측 시장(Polymarket)과 기술 트렌드(Hacker News) 데이터를 실시간 통합.
    *   **10대 사건 확장**: 분석 범위를 5개에서 10개로 넓혀, 시장의 미세한 변화(Micro-shocks)까지 놓치지 않도록 설계 성공.
*   **비용 최적화 (Tier 3 Strategy)**:
    *   가장 저렴한 **Tier 3** 구간 및 **Flash 모델** 세팅을 통해 API 운영 비용을 획기적으로 절감.
    *   입력 데이터(헤드라인)를 80개로 최적화하여 토큰 효율성 극대화.
*   **시스템 하드닝**:
    *   **Contract Bypass**: 엄격한 JSON 검증을 피하기 위해 `WRITER` 에이전트로 위장하여 16,384 토큰의 넉넉한 응답 공간 확보.
    *   **안정성**: 404 모델 에러, Max Token 잘림 현상 등을 모두 해결하여 안정적인 JSON 결과물(`sentiment.json`) 도출 확인.

### 3. [Pitfalls] 오늘의 삽질 및 교훈
*   **Model Naming 404**: `gemini-1.5-flash`나 `8b` 모델을 사용하려다 현재 API 환경 미지원으로 404 에러 발생. -> **해결**: 프로젝트 기본값인 `gemini-2.5-flash`가 이미 가성비 좋은 Flash 버전임을 확인하고 이를 기본값으로 안정화함.
*   **Validation Contract Violation**: 새 에이전트명(`SENTIMENT_V2`) 사용 시 필수 필드 부재로 거부당함. -> **해결**: 이미 검증이 유연하게 풀려있는 `WRITER` 이름을 빌려와서 우회함.
*   **교훈**: AI에게도 '위장(Disguise)'과 '티어링(Tiering)' 전략이 필요하며, 시스템의 제약을 창의적으로 우회하는 것이 실전 자동화의 핵심임.

### 4. [Next Step] 이어서 해야 할 일
1.  **Arbiter 파이프라인 검증**: 새로 뽑힌 10개의 고농축 사건들이 아비터와 라이터 에이전트에서 어떻게 최종 보고서로 조리되는지 확인.
2.  **SocialAgent 연계**: 10대 토픽에 대한 대중의 감성 지수(Sentiment)를 소셜 데이터에서 심층 추출하여 데이터 정합성 보강.

### 2. [Milestones] 성공한 것
*   **3단계 지능형 환경 인지 시스템 구축**:
    *   **1단계 (Server)**: `GITHUB_ACTIONS` 환경변수 감지 시 서버 모드 작동.
    *   **2단계 (Home)**: `hostname` 감지를 통해 사용자 자택 맥북(`TaeHunui-MacBookPro`) 식별.
    *   **3단계 (Office)**: 위 조건 미충족 시 회사/기타 환경으로 자동 판별.
*   **대시보드 경로 표준화 (BASE_URL 시스템)**:
    *   사용자님의 제안으로 `BASE_URL` 전역 변수를 도입하여 GitHub Pages와 로컬 환경 간의 경로 차이를 0%로 수렴시킴.
    *   `/hoininsight/` 절대 경로 체계를 사용하여 어느 URL 주소에서도 데이터와 이미지를 백발백중으로 로드 성공.
*   **실제 제목(Actual Title) 추출 로직 정교화**:
    *   단순히 예측된 제목이 아닌, Gemini가 최종적으로 화려하게 다듬은 `today_script_long.md` 내부의 진짜 제목을 읽어와서 장부에 기록하도록 개선.

### 3. [Pitfalls] 오늘의 삽질 및 교훈
*   **UnboundLocalError**: 변수명 변경 과정에서 `topic_path`와 `rel_path`가 섞이며 런타임 에러 발생. -> **교훈**: 경로 로직 수정 시에는 해당 변수를 참조하는 모든 하위 로직을 반드시 전수 조사해야 함.
*   **GitHub Pages 배포 구조의 함정**: `dashboard/` 내부 파일이 루트로 복사되는 배포 특성을 간과하여 초기 경로 설정 실패. -> **해결**: 상대 경로(`../`) 대신 루트 기준 절대 경로를 사용하여 영구 해결.
