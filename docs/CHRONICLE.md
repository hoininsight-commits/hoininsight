## 📅 2026-04-27 (오늘의 사냥 및 시스템 구축)

### 1. [Context] 오늘의 시작
*   사용자가 회사 맥에서 작업 재개 요청. 서버와 로컬의 소스 불일치 가능성 확인 및 전체 파이프라인 재수집 지시.
*   Gemini 503 서버 오류로 인해 사냥 리포트 품질이 저하된 상태에서 작업 시작.

### 2. [Milestones] 성공한 것
*   **유튜브 자막 자동 배달 시스템 구축**: 
    *   23, 05, 11, 17시(KST) 자동 수집 스케줄러(`youtube_learner.yml`) 생성.
    *   `scripts/auto_learner.py`를 통해 회차(1~4회) 자동 판별 로직 구현.
    *   `TelegramNotifier`를 통해 자막 전문(Full Text)을 분할 전송하는 기능 탑재.
    *   파일명 규칙: `YYYYMMDD_N회차_제목.txt`로 통일.

### 3. [Pitfalls] 오늘의 삽질 및 교훈
*   **DART API 실패**: 로컬 환경변수 미설정 또는 API 호출부 점검 필요. 다음 세션에서 가장 먼저 확인할 것.
*   **Python Import Error**: `youtube_watcher.py` 수정 시 `import re`를 누락하여 실행 에러 발생. -> **교훈**: 정규표현식 사용 시 항상 임포트 체크 필수.
*   **Venv 이식성 문제**: 기존 `hoin_venv`가 절대경로 기반으로 생성되어 타 기기 이식 불가. -> **해결**: `hoin_venv_local`로 새로 생성하여 해결. (Venv는 절대 푸시하지 말 것)

### 4. [Mistakes to Avoid] 다시는 하지 말 것
*   제미나이가 503 에러를 뱉을 때 무리하게 Tier 1 분석을 시도하지 말 것. (비용만 날릴 수 있음)
*   유튜브 자막 수집 시 쿠키 세션이 만료되면 `yt-dlp` 에러가 날 수 있으니 수시로 체크할 것.

3.  **Telegram 알림 최적화**: 자막이 너무 길 경우 가독성을 위해 요약본과 전문을 선택적으로 보내는 기능 고민.

    *   **인위적 편향 제거**: "글로벌 우선", "숫자 강조" 등 인간이 개입한 모든 가이드라인을 삭제함.

    *   **순수 페르소나 동화**: 스크립트 작성 시 인위적인 문체 지침 대신, 데이터의 본질을 가장 잘 전달할 수 있는 '사냥꾼'의 목소리를 스스로 선택하게 함.
*   **RSS 수집 복구**: YouTube의 404 차단 정책을 우회하기 위한 User-Agent 최적화 완료.

### 2. [Pitfalls] 오늘의 교훈
*   **가이드라인의 위험성**: 성능을 높이려는 인위적인 가이드라인이 오히려 데이터의 순수성을 해치고 판단을 왜곡할 수 있음. 최고의 고도화는 가이드를 주는 것이 아니라, **가이드 없이도 본질을 꿰뚫는 지능**을 확보하는 것임.

## 📅 2026-04-28 (KST 시차 극복 및 동기화 최적화)

### 1. [Context] 오늘의 시작
*   사용자로부터 "새벽 4시에 보고서를 받았는데 왜 아직 월요일이라고 하나?"라는 클레임 제기.
*   분석 결과, 서버의 시스템 시각(UTC)과 한국 시각(KST)의 9시간 차이로 인해 날짜 롤오버가 늦어지는 '타임라인 래그(Timeline Lag)' 버그 발견.

### 2. [Milestones] 성공한 것
*   **전 시스템 KST 동기화 (v17.6)**: 
    *   `Arbiter`, `WhyGenerator`, `Collector`, `Learner`, `Watcher` 등 모든 핵심 모듈의 `datetime.now()`를 `src.utils.target_date.get_now_kst()`로 교체.
    *   이제 어떤 서버 환경에서도 한국 시장 기준의 정확한 '오늘'과 '내일'을 인식함.
*   **자동 학습기 회차 로직 정상화**: UTC 19시를 4회차가 아닌 KST 04시(1회차)로 정확히 판별하도록 수정.

### 3. [Pitfalls] 오늘의 삽질 및 교훈
*   **Timezone Blindness**: 로컬에서는 KST로 작동하더라도 배포 환경이나 배치 환경에서는 UTC로 작동할 수 있음을 간과함. -> **교훈**: 금융 데이터 엔진에서는 절대 시스템 시각에 의존하지 말고, 명시적 타임존(KST)을 강제해야 함.
*   **Multi-File Edit 실수**: 한 번의 툴 호출로 여러 파일을 수정하려다 경로 인식을 실패함. -> **교훈**: 파일별로 개별 수정하거나 경로를 확실히 명시할 것.

### 4. [Next Step] 이어서 해야 할 일
1.  **DART 수집 성공 여부 재검증**: KST 동기화 이후 공시 검색 범위(3일)가 정확히 작동하는지 모니터링.
2.  **두산에너빌리티 데이터 주입**: 실제 사냥꾼이 오늘 공략한 두산에너빌리티의 핵심 로직(SMR 파운드리 등)이 다음 엔진 가동 시 반영되는지 확인.

### 2. [Pitfalls] 오늘의 삽질 및 교훈

*   **교훈**: AI의 지능만큼 중요한 것은 **데이터의 신선함(Freshness)**이며, 예외 상황에서 시스템이 거짓을 말하지 않도록 엄격한 검증 로직이 필수적임.
